# hermes-molstar

Offline-first Mol* structure preview plugin for Hermes Desktop.

## First release goal

Open local PDB/mmCIF structures in a reusable viewer pane, either manually or from a chat directive, without modifying Hermes core. Bundle Mol* rather than relying on a CDN.

- Scope and acceptance criteria: [TASK.md](TASK.md)
- Working constraints: [AGENTS.md](AGENTS.md)
- Initial feasibility assessment: [docs/feasibility.md](docs/feasibility.md)

Implementation, installation and test commands will be documented by the implementing Codex CLI session. This initial scaffold is not a completed plugin.
